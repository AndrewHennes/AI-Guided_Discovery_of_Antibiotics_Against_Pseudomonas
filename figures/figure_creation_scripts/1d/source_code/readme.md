# Figure 1d generation code

`shared/figure1_current_analysis.py` contains the current `counts()` implementation used for the final Figure 1d. It reads the four compressed input snapshots, canonicalizes positive structures, counts unique hits per strain and dataset, and draws the bar plot.

Run `reproduce_counts_1d.py` to reproduce the final count table and direct bar-plot exports in `/Users/asselism/Documents/Codex/2026-09-21/please-create-an-html-file-that/outputs/final_figure1_source_reproduction/1d/d`. The existing `../unique_hit_counts_across_datasets_d.py` exports the assembled panel with its panel letter. Input paths are absolute and use the snapshots in the methods root. No command-line arguments are required.

`original_dataset_hit_count_analysis.py` records the earlier dataset-comparison implementation from this task. Its original inputs and runnable package are retained in the methods root's `dataset_hit_counts` folder. The current four-dataset plot is generated by `reproduce_counts_1d.py`.
