# Undesigned analyses

- `tsne_102_delta6_model_compounds_with_filtered_8k` contains the standardized joint t-SNE of the supplied 102 compounds with the filtered Broad 8K library.
- `tsne_102_delta6_model_compounds_with_8k_coadd_ecbd` expands the background to all valid structures from filtered 8K and the latest filtered CO-ADD and ECBD datasets with the selected compounds removed. All three libraries share the same gray background color.
- `princeton_bio_ic50_od600_resazurin_four_replicates` contains independent four-parameter IC50 fits for each of four WT and four Δ6 replicate rows in three plate readouts, with the original plate files, fitted parameters, normalized data, and SVG/PDF/PNG plots.

Each analysis contains reproduction scripts, original source snapshots, intermediate data, and SVG/PDF/PNG outputs. The chemical-space analyses also include standardized structures and embedding coordinates.
