# Figure 1g, version 024

## Methods

Compounds were selected directly from `Broad_8K_Antibiotic_Activity_Dataset_Filtered_.csv` using the supplied binary activity labels. The older Figure 2d property table was not used. Molecular structures were parsed with RDKit 2025.09.1 and identified by canonical isomeric SMILES. Stereochemistry and disconnected fragments were retained. Duplicate structures were combined using logical OR for positive activity calls within each strain. No compound was excluded because of a missing continuous growth-inhibition measurement.

The WT group contains all eight WT-active structures. The Δ40 group contains all five Δ40-active structures. The Δ3 group contains 31 structures active in Δ3 and inactive in WT. The Δ6 group contains 85 structures active in Δ6 and inactive in both Δ3 and WT. The supplied dataset has 39 total Δ3 hits and 124 total Δ6 hits. All eight WT hits are also Δ3 hits, and all 39 Δ3 hits are also Δ6 hits. The requested exclusions therefore yield 31 and 85 compounds. Four WT hits are also Δ40 hits. The four displayed groups contain 129 observations representing 125 unique structures. These definitions are stated in the caption, while the figure labels use only WT, Δ40, Δ3, and Δ6 with their sample sizes. No inactive comparison group is shown.

Topological polar surface area (TPSA) was calculated with `rdMolDescriptors.CalcTPSA(mol, includeSandP=False)`. LogP was calculated with `Crippen.MolLogP`. Amine count is the total number of primary, secondary, and tertiary amine nitrogen atoms, including protonated forms and amines attached to aromatic carbon atoms. Aromatic ring nitrogens, amides, thioamides, sulfonamides, amidines, guanidines, cyanamides, imines, nitriles, nitro groups, amine oxides, and quaternary ammonium groups are excluded. The exact query is provided in `methods/amine_descriptor.py`, along with 33 functional-group checks. This descriptor counts structural amine sites and does not predict their protonation state at assay pH. Separate primary, secondary, and tertiary amine counts are included in the data table.

Boxes show the first and third quartiles, with a line at the median. Whiskers reach the most extreme observations within 1.5 interquartile ranges of the box. Every compound is overlaid with identical marker styling and a deterministic horizontal jitter rule. Box-plot outlier markers are suppressed because those observations are already included in the complete point layer. No vertical jitter or point sampling is used. Values are not clipped. Observed ranges are 0 to 206.07 square ångströms for TPSA, 0 to 3 for amine count, and approximately 0.230 to 7.634 for logP. The axes span −8 to 220, −0.2 to 3.25, and 0 to 8, respectively. Small margins below zero for TPSA and amine count keep zero-valued points fully visible. The original green, orange, red, and purple strain colours are retained.

Group membership was checked independently using sets of positively labelled source records. Descriptor values for the 124 structures shared with the previously verified hit table were checked against that table. The additional Δ40 structure was calculated using the same descriptor functions. The plotting audit checks all 387 points across the three panels.

Only panel g is replaced in the Illustrator document. Panel f is retained from version 023 and must pass an exact rendered comparison before delivery. The other figure panels are retained. The original supplied Illustrator file and version 023 remain available.

## Caption

**g**, Physicochemical properties of activity-defined compound groups. WT contains all WT-active molecules (n = 8), and Δ40 contains all Δ40-active molecules (n = 5). Δ3 contains molecules active in Δ3 but inactive in WT (n = 31). Δ6 contains molecules active in Δ6 but inactive in both Δ3 and WT (n = 85). Activity is defined by the supplied binary labels at 80% growth inhibition. Four molecules occur in both the WT and Δ40 groups. The panels show topological polar surface area (TPSA, $\mathrm{\AA}^2$), number of primary, secondary, and tertiary amines combined, and Wildman–Crippen logP. Amine counts include protonated forms and exclude amides and aromatic ring nitrogens. Boxes show interquartile ranges, central lines show medians, and whiskers extend to the most extreme observations within 1.5 interquartile ranges of the box. Every compound is shown as a point using the same horizontal jitter rule and marker style in all groups. Points may overlap, especially for integer amine counts. All values are included within the displayed axes. Green, orange, red, and purple denote WT, Δ40, Δ3, and Δ6, respectively.

## Reproduction

`methods/reproduce_activity_group_panel.py` generates the data tables, checks the cohort definitions, and writes the three-property panel as PDF, SVG, and PNG. `methods/integrate_activity_groups_in_illustrator.jsx` imports the panel into the existing panel g region of version 023 and saves `Figure1_v024_TPSA_amines_LogP.ai`. `methods/export_activity_group_figure.py` exports a matching vector PDF and 300 dpi review PDF from the saved native Illustrator file. It checks the property labels, counts, fonts, and unchanged artwork outside panel g, including an exact comparison of panel f. All code uses absolute input and output paths and requires no command-line arguments.
