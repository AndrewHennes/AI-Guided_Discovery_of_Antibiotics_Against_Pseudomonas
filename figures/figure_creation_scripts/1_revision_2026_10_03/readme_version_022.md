# Figure 1 revision methods, version 022

Run `reproduce_revision.py` to create the current logarithmic density violins in panel f, the six property box-and-whisker charts in panel g, the updated compound count panel, and the analysis tables. `violin_panels.py` contains the inhibition violin definitions and property axis limits. `property_boxplots.py` renders panel g with median lines, interquartile boxes, 1.5-interquartile-range whiskers, and outlier points. The 8K file is read directly from its absolute source path. Activity groups use its WT and Δ6 binary columns, giving eight WT hits, 124 Δ6 hits, and 116 Δ6-only hits. All three compounds with missing continuous WT measurements remain Δ6-only hits. The earlier Figure 2d property list is not used.

Panel f uses all available continuous measurements for each strain. Violin half-widths use the same logarithmic density transformation and reference floor across all strains. Panel g shows heavy atom count, logP, TPSA, log10 IPC, number of amines, and aromatic rings, with tighter display ranges. Heavy atoms replace molecular weight, amines replace rotatable bonds, and log10 IPC replaces formal charge. `amine_descriptor.py` counts primary, secondary, and tertiary amines including protonated forms, and checks 33 functional-group examples. The exact exclusions are documented in the methods. All 7,985 heavy atom counts were independently verified by counting atoms with atomic number greater than one. Property groups remain 8, 116, and 7,861 structures.

Run `validate_revision.py` for independent activity and count checks. `validate_violin_revision.py` documents the descriptor and panel f density checks from version 018, whose calculations remain unchanged. Run `update_heavy_atom_panel_in_illustrator.jsx` in Illustrator to replace only panel g in version 021 and save `Figure1_v022_heavy_atoms.ai`. Other edits in that source document are preserved. Then run `export_heavy_atom_figure.py` to export the matching vector PDF, PNG, and lightweight 300 dpi raster review PDF. The Illustrator update script is intended to run once per source document.

Scripts have no command-line arguments. Outputs always go to the absolute revision directory specified in their source. Other datasets use the included snapshots. Provenance is recorded in `saved_inputs/source_manifest.json`. Python package versions are in `requirements_revision.txt`. No GPU is required.

The existing chemical-space maps and original replicate panels are retained. See `METHODS_AND_CAPTION.md` for definitions, caption text, and the distinction between screen annotations and the available data.

Earlier scripts for versions 015 through 021 are retained as historical workflows. `remove_stray_placed_figures.jsx` removed the old Figure 1 copy above the artboard and the linked Figure 2 below it to create version 017. Version 018 added the logarithmic density violins and log10 IPC. Version 019 restored box-and-whisker plots for panel g. Version 020 replaces molecular weight with heavy atom count and rotatable bonds with amine count, retaining the box plots and log10 IPC. Earlier native update and preview scripts do not produce the current revision.

Version 022 restores heavy atom count in place of alcohol count. The delivered native artwork is an exact copy of the verified version 020 figure, which already has the requested descriptors and current layout. `restore_verified_heavy_atom_artwork.py` records this restoration and refuses to overwrite an existing restored document. Use the normal panel-generation and Illustrator-update workflow for new analysis results. Alcohol counts remain in exported data as additional fields but are excluded from the current six-property comparison.
