# Figure 1 revision, version 022

## Methods text

The new panels were generated directly from `Broad_8K_Antibiotic_Activity_Dataset_Filtered_.csv`. The earlier Figure 2d property table was not used to define compounds or activity groups. Molecular structures were parsed with RDKit 2025.09.1 and identified by canonical isomeric SMILES. Stereochemistry and disconnected fragments were retained. No additional protonation, tautomer, or salt standardization was performed. The supplied file contains 7,997 records representing 7,985 unique structures.

Activity groups were defined by the supplied `WT_Binarized_at_80_Percent_Growth_Inhibition` and `Delta6_Binarized_at_80_Percent_Growth_Inhibition` columns. Repeated records for the same structure were combined by logical OR within each strain. Wild-type (WT) hits had a WT activity label of 1. Δ6-only hits had a WT label of 0 and a Δ6 label of 1. Inactives had labels of 0 in both columns. There were eight WT hits and 124 Δ6 hits. All eight WT hits were also Δ6 hits, leaving 116 Δ6-only hits and 7,861 structures inactive in both strains. The activity labels were complete for all structures. No compounds were excluded from this property comparison because a continuous inhibition measurement was missing. Inactive refers to the recorded WT and Δ6 activity labels and does not imply inactivity in every strain or at every concentration.

Mean percentage growth inhibition was taken from the corresponding continuous measurement columns. Each strain's violin used all available measurements for that strain, with repeated measurements averaged within a canonical structure. The WT distribution contained 7,671 measured structures and each mutant distribution contained 7,985 measured structures. Missing continuous values were not imputed from binary activity labels. The displayed n = 7,994 is the screen annotation. Density sample sizes are reported separately above.

Gaussian kernel density estimates used a common bandwidth of two percentage points. Violin half-widths use a shared base-10 logarithmic density transformation to make low-density tails visible. For probability density $p(x)$ per percentage point, the half-width is $w(x) = 0.405 \max[\log_{10}(p(x)/p_0), 0] / \log_{10}(p_{\max}/p_0)$, where $p_0 = 10^{-5}$ and $p_{\max}$ is the largest density over all four strains. Density values below the common floor have zero displayed width. Each violin is mirrored around its strain centre, and widths are not rescaled separately by strain. The inhibition axis remains linear. Measurements below zero and above 100% were retained. Black bars indicate interquartile ranges and white points indicate medians. The dashed line marks 80% inhibition. Annotations report eight WT hits, five ΔOMP40 hits, 39 ΔE-pump3 hits, and 124 ΔE-pump6 hits. Hit percentages remain available in the analysis table using the actual measured structure counts, but are not displayed on panel f.

Heavy atom count, Wildman–Crippen logP, topological polar surface area (TPSA), the base-10 logarithm of the information content descriptor (IPC), amine count, and aromatic ring count were calculated consistently for all three property groups. Heavy atoms were counted using `Mol.GetNumHeavyAtoms()` and independently verified as atoms with atomic number greater than one. Hydrogen atoms were excluded. Disconnected fragments in the supplied molecular structure were retained. LogP was calculated using `Crippen.MolLogP`, TPSA using `CalcTPSA` with sulfur and phosphorus contributions disabled, IPC using `GraphDescriptors.Ipc(mol, avg=False)`, and aromatic rings using `CalcNumAromaticRings`. IPC measures information content derived from the molecular graph's characteristic polynomial coefficients ([RDKit definition](https://www.rdkit.org/docs/source/rdkit.Chem.GraphDescriptors.html#rdkit.Chem.GraphDescriptors.Ipc)). Every IPC value was finite and positive, so $\log_{10}(\mathrm{IPC})$ was calculated directly without a pseudocount. Alcohol count, molecular weight, rotatable bonds, and formal charge remain in the exported data for provenance but are no longer plotted or included in the six-property statistical comparison.

Amine count is the total number of primary, secondary, and tertiary amine nitrogen atoms, including protonated forms and amines attached to aromatic carbon atoms. Nitrogen atoms within aromatic rings are excluded. The structural query follows the exclusions in RDKit's amine functional-group definition ([RDKit functional-group hierarchy](https://github.com/rdkit/rdkit/blob/master/Data/Functional_Group_Hierarchy.txt)), with additional valence, charge, and bond restrictions. Matched atoms have one to three carbon neighbours and no noncarbon heavy-atom neighbour. Amides, thioamides, sulfonamides, amidines, guanidines, cyanamides, imines, nitriles, nitro groups, amine oxides, and quaternary ammonium groups are excluded. This definition counts structural amine sites and does not predict their protonation state at assay pH. The exact query and 33 checked functional-group examples are provided in `methods/amine_descriptor.py`. Primary, secondary, and tertiary amine counts are also exported separately.

Property box plots show the median as a horizontal line and the interquartile range as a box. Whiskers extend to the most extreme observations within 1.5 interquartile ranges below the first quartile or above the third quartile. Observations beyond the whiskers are shown as points when within the displayed axes. All eight WT observations are overlaid with deterministic horizontal jitter. Box and whisker calculations use the complete group before the display limits are applied.

The displayed property axes are 5 to 40 for heavy atom count, 0 to 6.5 for logP, 0 to 150 square ångströms for TPSA, 1.5 to 9.5 for $\log_{10}(\mathrm{IPC})$, −0.4 to 4.4 for amine count, and −0.4 to 5.4 for aromatic rings. Box and whisker calculations use all observations. Boundary triangles mark values beyond the displayed range. The numbers outside each limit are recorded in `tables/property_boxplot_display_audit.csv`. All eight WT observations lie inside every displayed range.

Exploratory pairwise comparisons used two-sided Mann–Whitney tests with asymptotic, tie-corrected p values. Benjamini–Hochberg correction was applied across all 18 comparisons of the six displayed descriptors. Rank-biserial effect sizes and adjusted p values are provided in the tables.

Compound counts were calculated from the supplied filtered 8K, 39K, ECBD, and CO-ADD files. Each canonical isomeric structure contributed once per dataset and strain. Existing binary calls were combined by logical OR within each structure. Missing binary calls were retained as missing. Nine records with unparseable structures were excluded across 39K and CO-ADD. None carried a positive call in the displayed assays. Counts represent the supplied dataset annotations, including the ECBD hit annotation, and do not assume identical experimental conditions across libraries.

Descriptor definitions are documented by RDKit ([heavy atoms](https://www.rdkit.org/docs/source/rdkit.Chem.rdchem.html#rdkit.Chem.rdchem.Mol.GetNumHeavyAtoms), [logP](https://www.rdkit.org/docs/source/rdkit.Chem.Crippen.html), [molecular descriptors](https://www.rdkit.org/docs/source/rdkit.Chem.rdMolDescriptors.html)).

## Reproduction

`methods/reproduce_revision.py` reads the current 8K CSV directly using its absolute path and generates the panels and analysis tables. Other datasets use the supplied column snapshots with recorded source checksums. The older Figure 2d property list is not an input. Scripts require no command-line arguments and write products to the configured absolute revision directory.

`tables/8K_WT_and_Delta6_only_hit_properties.csv` contains all 124 Δ6 hits, including the eight WT hits. `tables/8K_Delta6_only_116_compounds.csv` contains the 116 exclusive Δ6 hits. Both tables include canonical structures, source row indices, catalogue identifiers, source activity labels, and recomputed properties. `methods/validate_revision.py` checks the groups independently against positive source records and verifies inclusion of the three compounds with missing continuous WT values.

`methods/violin_panels.py` defines panel f and the property display limits. `methods/property_boxplots.py` renders panel g, and `methods/amine_descriptor.py` defines and checks amine counting. Version 022 restores the verified version 020 Illustrator artwork byte for byte, returning the first property subplot to heavy atom count. The current data values were verified against version 020 before restoring its summaries and statistical comparisons. The native restoration is recorded in `tables/heavy_atom_restore_provenance.json` and implemented in `methods/restore_verified_heavy_atom_artwork.py`.

For freshly regenerated analysis panels, `methods/update_heavy_atom_panel_in_illustrator.jsx` replaces panel g in version 021 and saves `Figure1_v022_heavy_atoms.ai`. `methods/export_heavy_atom_figure.py` creates the vector PDF, PNG, and 300 dpi raster review PDF from the saved native AI file and verifies that artwork outside panel g is pixel-identical to version 021. The original supplied Illustrator file remains unchanged.
