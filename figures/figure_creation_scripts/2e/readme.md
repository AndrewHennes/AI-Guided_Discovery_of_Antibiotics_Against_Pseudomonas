# Figure 2e

Run `deepflux_efflux_score_compound_predictions_and_wild_type_hits_e.py` to export the panel using the shared Figure 1 strain palette. Prediction markers are open black circles with the same geometry and size as the green WT markers.

The supplied SVG is included in `shared/assets/figure2/panel_e_source`. Its six scatter groups are placed in the Figure 2 layout, retaining separate vector markers and the six embedded background images. The rendered component PDF is included for reproduction. Changing the supplied SVG requires librsvg (`rsvg-convert`) to rebuild that component PDF.

See `../README_Figure_2.md` for the assembled figure and export settings.
